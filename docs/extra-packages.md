# Extra Packages Overview

## Dolphin (File Manager) Enhancements :

- **dolphin-plugins:** adds plugins to Dolphin
- **ark:** the KDE archive manager to compress/extract directly from Dolphin's context menu.
- **kdegraphics-thumbnailers:** thumbnails for images (SVG, PSD, RAW).
- **ffmpegthumbs:** thumbnails for all video files.
- **taglib:** metadata and previews for audio files (MP3, FLAC cover art).
- **kimageformats:** support for modern image formats (AVIF, HEIC, WebP).
- **konsole:** allows opening the integrated terminal at the bottom of Dolphin by pressing F4 (Dolphin uses the Konsole KPart for this panel).
